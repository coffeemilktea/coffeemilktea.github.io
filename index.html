How it works

Static pages. Your data stays in the tab.

  1. 01

    Open a page

    Every tool is a single static HTML page served from GitHub Pages. No install, no account and no build step.

  2. 02

    Load a sample or your own file

    Every tool has a sample or demo button, so you can see it work before you paste a message or drop a DICOM file.

  3. 03

    It runs in your browser

    Files and messages are parsed in your browser and are not uploaded anywhere. The site sets no cookies and runs no analytics.

The one exception

The MWL Simulator’s External mode sends QIDO-RS queries to the DICOMweb URL you enter. Its Simulated mode makes no network requests.
